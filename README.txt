I-RISE READ v2.0 — upload package

Upload index.html, manifest.json, and sw.js to the ROOT of your existing GitHub Pages repository. Replace the old files and commit the changes. Refresh the published site; if needed, hard-refresh or clear its cache.

Includes 12 sample passages (4 Simple, 4 Moderate, 4 Hard), each linked to oral reading, vocabulary, and comprehension practice; optional browser speech-to-text; approximate transcript comparison; teacher-entered verified miscue counts; local progress records; CSV export.

IMPORTANT: These are sample passages and formative questions, not the official validated I-RISE 5.0 materials. Replace or validate them against your school-approved materials before formal use. Teacher verification is required. Records remain in this browser/device only; there is no cloud sync. Use learner codes and secure exported records.
