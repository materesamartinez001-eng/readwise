I-RISE READ v3.0 — revised web app package

UPLOAD: Replace index.html, manifest.json, sw.js in the ROOT of your existing GitHub Pages repository, then commit/push. GitHub Pages should serve the site over HTTPS.

NEW IN v3.0
- Reorganized into Decoding & Oral Reading, Vocabulary, Reading Comprehension, and Assessment & Student Progress.
- Separate decoding score entry (correct/total/percentage), plus vocabulary and comprehension results.
- Teacher-assigned performance level field: Frustration, Instructional, Independent. Apply your approved I-RISE criteria; this app does not calculate levels automatically.
- Actual audio recording with microphone permission, playback, and download. Audio is not uploaded and is not stored in the progress records.
- Optional speech-to-text remains separate from actual audio recording. Transcript comparison is approximate and requires teacher verification.
- CSV export includes all three assessment areas and teacher notes.

IMPORTANT CONTENT NOTE
The sample passages and quiz items carried forward from v2.2 are supplementary demonstration content, not transcriptions of the 2025 I-RISE workbook. Use the printed workbook as the primary teaching resource. Enter the workbook activity/passage title in the provided field. The full 155 MB workbook is not embedded in this lightweight website package.

RECORDING REQUIREMENTS & PRIVACY
Audio recording requires a supported browser, device microphone, user permission, and a secure HTTPS site (such as GitHub Pages). Browser/device support varies. The learner or teacher must download the audio file and store it securely. Do not use full student names in filenames. Audio is not sent to a server by this app.

DATA & ASSESSMENT LIMITATIONS
Progress records are stored in local browser storage on the current device only. Export CSV regularly and keep it secure. Use learner codes. This is a formative companion, not a validated diagnostic instrument and not a replacement for Phil-IRI or other approved assessment. Teacher judgment and school-approved scoring criteria remain essential.
